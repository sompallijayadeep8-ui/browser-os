One more thing I want us to do—and I think this will make the project much more valuable:

No tutorials.

We'll treat this like a real software project:

We discuss the feature.
We design it.
You think about the implementation.
You code it.
I review it like a senior engineer.
We refactor if needed.

That process will teach you far more than copying code from a video. By the time you finish,
you'll have built something substantial and gained the confidence to tackle complex projects on your own.
